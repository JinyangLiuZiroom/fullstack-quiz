# Redis 数据类型（前置知识补完）

> 一句话：Redis 是内存 KV 库，支持多种数据结构，不同场景用不同结构。

## 你应该会什么（检验）
- 基本数据结构：String / Hash / List / Set / ZSet
- 知道各自典型用途

## 30 秒上手
```
String 键值      -> 缓存、计数器（INCR）
Hash  字段表     -> 用户信息（user:1 {name,age}）
List  队列       -> 最新消息、简单队列
Set   去重集合    -> 点赞用户、标签
ZSet  有序集合    -> 排行榜（按分数排序）
```

## 一个练习
用 ZSet 的 `ZADD` + `ZREVRANGE` 实现一个「积分排行榜 Top10」。做完回主文章（模块九/十专门讲）。

## 常见误解
- `INCR` 只能用于数字字符串，对普通字符串会报错。
- ZSet 的「分数」决定排名，值可重复，靠分数排序。
