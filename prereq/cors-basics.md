# 同源与跨域（前置知识补完）

> 一句话：浏览器出于安全，禁止页面向「不同源」的地址发请求，这就是跨域限制的由来。

## 你应该会什么（检验）
- 知道「同源」= 协议 + 域名 + 端口三者全同
- 知道前端 `localhost:5173` 调后端 `:8080` 是跨域

## 30 秒上手
```
同源：https://a.com  →  https://a.com     ✅
跨域：http://a.com  →  https://a.com     ❌ 协议不同
跨域：https://a.com →  https://b.com      ❌ 域名不同
跨域：https://a.com:5173 → https://a.com:8080 ❌ 端口不同
```

## 一个练习
用 DevTools Network 看一个失败请求，Console 里搜 "CORS" 看报错。做完回主文章（模块四专门讲怎么解）。

## 常见误解
- 跨域是**浏览器**拦的，不是服务器收不到；Postman 能通不代表前端能通。
- 解决靠服务端加 CORS 响应头，或开发期用 Vite 代理「骗」浏览器同源。
