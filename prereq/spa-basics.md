# 单页应用 SPA（前置知识补完）

> 一句话：SPA 整个站点只有一个 `index.html`，页面切换靠 JS 动态换内容，不真刷新浏览器。

## 你应该会什么（检验）
- 知道「单页应用」：整个站点只有一个 index.html
- 知道 URL 的 `path` / `query`（?后） / `hash`（#后）

## 30 秒上手
传统多页：点链接 → 服务器返回新 HTML → 整页刷新。
SPA：首次加载 index.html + JS，之后点导航 → JS 局部替换内容，URL 变但**不刷新**。
Vue Router 的 `history` 模式改 `path`，`hash` 模式改 `#`。

## 一个练习
打开一个 Vue 项目，在页面间点切换，观察地址栏变化但 Network 没重新请求 html。做完回主文章。

## 常见误解
- SPA 首屏慢（要下载整个 JS 包）；用路由懒加载缓解。
- `hash` 模式带 `#`，不会被发到服务器，刷新不会 404；`history` 模式刷新要服务器兜底。
