# 阻塞与非阻塞（前置知识补完）

> 一句话：阻塞 = 方法不返回，调用方干等；非阻塞 = 立刻返回，结果好了再通知。

## 你应该会什么（检验）
- 知道「阻塞」：方法不返回，调用方干等
- 知道网络 IO、锁等待都会阻塞线程

## 30 秒上手
```java
// 阻塞：这行不返回，线程就卡在这等数据库
List<User> list = repo.findAll();
// 非阻塞（响应式/异步）：立刻返回，数据到了回调通知
repo.findAllAsync().subscribe(list -> ...);
```

## 一个练习
想清楚：一个线程被「阻塞等 DB」时，它不能干别的事；所以高并发要靠「更多线程」或「非阻塞 IO」。做完回主文章（模块五/九涉及）。

## 常见误解
- 阻塞本身不是错，错在「用少量线程干大量阻塞活」导致线程耗尽；用线程池或非阻塞模型解决。
