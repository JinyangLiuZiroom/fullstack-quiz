> 每篇统一结构：学习目标 / 前置知识 / 核心原理 / 快速开始 / 进阶用法 / 常见坑与排错表 / 完整实战 / 最佳实践 / 自测清单 / 延伸阅读。

## 模块清单（10 篇）

### 测试理论与方法

## 推荐学习路径

```
1 测试基础与金字塔
   ↓
2 接口测试  → 3 功能测试  → 4 回归测试  → 5 冒烟测试  → 6 质量工程
   ↓
7 JUnit5 单测  → 8 Playwright  → 9 CI/CD（把 7/8 接进流水线）
   ↓
10 AI 辅助测试（贯穿全程提效）
```

**建议**：理论篇（1-6）先建立体系，再练工具（7-9），最后用 AI（10）给全流程提速。第 2/3 篇是日常最高频，优先吃透。
